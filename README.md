# Единая цифровая экосистема здравоохранения

Демонстрационный презентационный портал национальной цифровой системы здравоохранения
Республики Узбекистан: интерактивная карта экосистемы, операционный центр, слой данных,
искусственный интеллект, ГИС и архитектура платформы.

## Запуск

```bash
npm install
npm run dev       # разработка → http://localhost:5173
npm run build     # production-сборка в dist/
npm run preview   # локальный просмотр сборки → http://localhost:4173
```

## Структура

```
src/
  lib/            типы домена (types.ts), иконки, хуки
  data/           контент и показатели (12 направлений, регионы, статистика)
  services/       api.ts — единая точка получения данных
  components/
    TopBar/       шапка с навигацией
    Hero/         главный экран: орбитальная карта экосистемы (+ мобильная версия)
    Panel/        информационная панель направления (типизированные блоки)
    Sections/     ОперЦентр · Данные · ИИ · ГИС · Архитектура
    Footer/
  styles/         tokens.css (дизайн-токены) + global.css
```

## Как устроен контент

Вся смысловая часть отделена от компонентов:

- **`src/data/directions.ts`** — 12 направлений экосистемы. Панель каждого направления
  описана типизированными блоками (`kpis`, `chips`, `bars`, `flow`, `graph`, `stack`,
  `link`, `text`) — см. `PanelBlock` в `src/lib/types.ts`.
- **`src/data/stats.ts`** — национальные показатели, KPI операционного центра,
  лента телеметрии, уровни архитектуры.
- **`src/data/regions.ts`** — 14 регионов: геометрия карты + показатели.

## Подключение реальных данных

Интерфейс получает данные только через **`src/services/api.ts`**. Чтобы подключить
DMED, государственные информационные системы, аналитические витрины, AI-модули или ГИС,
достаточно заменить реализацию функций на `fetch` к соответствующим API — типы и
компоненты не меняются:

```ts
export async function getNationalStats(): Promise<NationalStats> {
  const r = await fetch(`${API_BASE}/v1/stats/national`)
  return r.json()
}
```

## Данные

Показатели — демонстрационные. Агрегаты интеграций (61 направление обмена, 16 ведомств,
25 правовых актов, динамика 2020–2026) соответствуют реестру межведомственного обмена
Министерства здравоохранения по состоянию на март 2026 года.

Карта регионов — [Simplemaps.com](https://simplemaps.com) (free license).

## Технологии

Vite · React 19 · TypeScript · CSS Modules. Без сторонних UI-библиотек:
карта экосистемы, графики и карта страны — собственный SVG.

Поддерживается: клавиатурная навигация, `prefers-reduced-motion`,
адаптив от 360 px до широких экранов.
